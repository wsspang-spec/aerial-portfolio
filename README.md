# Aerial portfolio

Personal site for aerial films and stills. Plain HTML/CSS/JS, hosted on GitHub Pages.

- **Change text, films, photos, links:** edit `content.js` only.
- **Add a film:** upload to YouTube (16:9, 4K, embedding allowed), copy the ID after `watch?v=`, add an entry to `films`.
- **Add photos:** put compressed JPGs (about 2000px wide, under 500 KB) in `/images`, then list them under `stills` as `images/name.jpg`.
- **Look and layout:** `styles.css`. Colors are the variables at the top.
